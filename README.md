## How it's works
LeTube is a set of 10 addressable LED tubes controlled wirelessly from a lighting control software such as QLC+.
The system uses an ESP32 as the main controller. QLC+ generates the lighting data and sends it over the network using the Art-Net protocol. The ESP32 receives the Art-Net packets over Wi-Fi and converts the received DMX values into the appropriate data for the addressable LED strip.
The general data flow is:
QLC+
  │
  │ Art-Net over Wi-Fi
  ▼
ESP32
  │
  │ LED data
  ▼
WS2815 LED strip
  │
  ├── Tube 1
  ├── Tube 2
  ├── Tube 3
  ├── ...
  └── Tube 10
Each tube contains a 1-meter section of individually addressable WS2815 LEDs. This means that the LEDs are not simply switched on or off together: each individual pixel can receive its own color and brightness value.
The ESP32 receives the Art-Net data and maps the DMX channels to the corresponding LED pixels. For example, changing a color or intensity in QLC+ results in a change in the corresponding pixels on the tubes.
The LED strips are powered directly from a dedicated 12 V power supply through power distribution busbars. The WS2815 strips use 12 V, while the ESP32 is powered separately through its own low-voltage supply.
The use of WS2815 LEDs also makes it possible to power the installation efficiently while keeping the controller hardware simple. Unlike my original design, there is no individual microcontroller or custom PCB inside every tube. One ESP32 controls the complete set, which significantly reduces the cost and complexity of the project.
The final system therefore consists of three main parts:
QLC+: generates and controls the lighting effects.
ESP32: receives Art-Net and controls the addressable LEDs.
10 WS2815 LED tubes: display the lighting effects generated by QLC+.

This approach allows the ten tubes to behave as a single addressable lighting system while remaining relatively inexpensive and easy to reproduce.
